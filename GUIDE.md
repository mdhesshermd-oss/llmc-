# Руководство по установке и настройке AdvancedCarLockRU

Этот мод добавляет продвинутую систему кодовых замков для автомобилей в DayZ с полноценной серверной частью, сохранением состояния и админ-панелью.

## 🛠 Сборка мода (создание .PBO)

Для сборки вам понадобятся **DayZ Tools** (доступны в Steam).

1. Скопируйте папку `AdvancedCarLockRU` в вашу рабочую директорию DayZ (например, `P:\`).
2. Откройте **Workbench** или используйте **Mikero's Tools** (PboProject).
3. Запакуйте папку `AdvancedCarLockRU` в PBO файл с названием `AdvancedCarLockRU.pbo`.
4. Подпишите PBO вашим приватным ключом (.bisign).

## 🚀 Установка на сервер

1. Создайте в корне сервера папку мода, например `@AdvancedCarLockRU`.
2. Внутри создайте папку `Addons` и поместите туда ваш `AdvancedCarLockRU.pbo` и файл подписи `.bisign`.
3. Скопируйте ваш публичный ключ (.bikey) в папку `keys` на сервере.
4. Добавьте мод в параметры запуска сервера: `-mod=@AdvancedCarLockRU`.

## ⚙️ Настройка

После первого запуска сервера мод автоматически создаст необходимые файлы в папке профиля сервера (`$profile:AdvancedCarLock/`).

### 1. Настройка параметров (Config.json)
Файл: `profiles/AdvancedCarLock/Config.json`
```json
{
    "carUnlockToolType": "Lockpick",
    "carUnlockDuration": 60.0
}
```
* `carUnlockToolType`: Класс-нейм инструмента, которым можно взломать замок (по умолчанию отмычка).
* `carUnlockDuration`: Время взлома в секундах.

### 2. Настройка администраторов (Admins.txt)
Файл: `profiles/AdvancedCarLock/Admins.txt`
Просто впишите SteamID64 администраторов (каждый с новой строки):
```text
7656119xxxxxxxxxx
7656119yyyyyyyyyy
```
Администраторы видят дополнительные действия при взаимодействии с дверью машины: **[A]Узнать пинкод** и **[A]Сбросить пинкод**.

## 🎮 Функционал мода

* **Установка кода:** Если на машине нет кода, сядьте на водительское место и выберите "Создать код".
* **Доступ:** Если код установлен, его нужно ввести один раз за сессию. После этого вы сможете открывать/закрывать машину дистанционно.
* **Дистанционное управление:** Нажмите клавишу **U** (по умолчанию), чтобы заблокировать или разблокировать машину, если вы находитесь рядом (до 5 метров).
* **Взлом:** Если у вас есть отмычка, вы можете попытаться сломать замок. При успешном взломе отмычка ломается, а замок сбрасывается.
* **Сохранение:** Состояние замка и пин-код сохраняются после рестарта сервера.
* **Безопасность:** Пин-код хранится только на сервере и не передается другим игрокам через сетевые переменные.
