# Технические источники и справочные материалы

Для реализации поддержки гипервизора на различных архитектурах процессоров (Intel и AMD) были использованы официальные спецификации производителей и открытые исследовательские проекты.

## 1. Официальная документация процессоров
Это первоисточники для всех инструкций виртуализации и структур данных:
- **Intel® 64 and IA-32 Architectures Software Developer’s Manual (Volume 3C):** Содержит описание технологии **VMX**, инструкции **`VMCALL`** и структуры **VMCS**.
- **AMD64 Architecture Programmer’s Manual (Volume 2: System Programming):** Содержит описание технологии **SVM (Secure Virtual Machine)**, инструкции **`VMMCALL`** (аналог Intel VMCALL) и структур **VMCB** и **NPT**.

## 2. Различия в реализации (Intel vs AMD)
Хотя проект **HyperBone** (DarthTon) изначально сфокусирован на Intel VT-x, для поддержки вашего процессора **Ryzen 5 7535HS** логика была адаптирована на основе стандартов AMD:
- Инструкция `VMCALL` вызывает `VM-Exit` только на Intel. На AMD она вызовет исключение (#UD).
- Для AMD используется эквивалентная инструкция **`VMMCALL`**.

## 3. Исследовательские проекты
- **HyperBone (DarthTon):** Основная архитектура Manual Map и концепция EPT Shadowing.
- **SimpleVisor (несколько авторов):** Базовые примеры минималистичных гипервизоров для понимания процесса инициализации `VMXON` и `VMRUN`.

Эти материалы позволили создать универсальный интерфейс в файле `hypervisor_io.h`, который автоматически выбирает нужную инструкцию в зависимости от вашего железа.
