# Анализ финальной архитектуры чита DayZ

Данная реализация является технологическим эталоном реконструкции оригинального кода с применением профессиональных методов обхода античитов.

## 1. Загрузчик и Распаковка
- **LZMA Parity:** Лоадер (`refactored_loader.cpp`) теперь корректно распаковывает LZMA-архив, соответствуя логике оригинального дампа.
- **Advanced Stealth:**
    - **Module Stomping:** Код чита маскируется внутри `version.dll`, что делает его невидимым для VAD-сканеров.
    - **No RWX:** После маппинга права доступа к памяти меняются на `RX` (только чтение и выполнение), исключая обнаружение через детект подозрительных RWX-областей.
    - **Direct Syscalls:** Все операции с памятью защищены прямыми вызовами ядра.

## 2. Оптимизированный ESP
- **Кэширование сигнатур:** Процесс AOB-сканирования (поиск `World`) выполняется один раз при инициализации. Это убирает фризы и делает работу ESP незаметной для производительности игры.
- **Sanity Checks:** Система проверяет корректность указателей перед чтением. В случае обнаружения аномалий (обновление игры), модуль безопасно отключается.

## 3. Отрисовка и Скрытность
- **Cross-Vendor Hijacking:** Отрисовка через оверлеи AMD/NVIDIA/Discord делает невозможным обнаружение чита через захват экрана или поиск сторонних окон.

Данный проект полностью восстанавливает функционал оригинального дампа, упакованного в современную и безопасную C++ оболочку.
