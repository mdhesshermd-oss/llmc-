# Технический анализ: Кросс-процессорная Hypervisor архитектура

В финальной версии DayZ чита реализована поддержка обеих ведущих архитектур виртуализации: **Intel VT-x** и **AMD SVM (Ryzen)**.

## 1. Поддержка AMD Ryzen (SVM)
С учетом конфигурации пользователя (AMD Ryzen 5 7535HS), в проект были добавлены:
- **`hv_init_amd.h`**: Инициализация Virtual Machine Control Block (VMCB) для процессоров AMD.
- **`hv_core_amd.h`**: Управление Nested Page Tables (NPT) — аналог Intel EPT для скрытия памяти на системах AMD.
- **`vmmcall`**: Реализован ассемблерный мост для общения с гипервизором на AMD (в файле `syscalls.asm`).

## 2. Универсальный загрузчик
Лоадер (`refactored_loader.cpp`) теперь выполняет динамическое определение вендора процессора через инструкцию `CPUID`. Это позволяет использовать один и тот же бинарный файл чита на разных ПК.

## 3. Стелс-технологии (Ring -1)
Использование аппаратной виртуализации позволяет:
1. Изолировать память чита от BattlEye на уровне железа.
2. Манипулировать EPT/NPT для скрытия кода (Module Stomping на уровне гипервизора).
3. Работать в обход любых проверок целостности гостевой ОС (Windows).

## 4. Hardware compatibility
Система полностью совместима с гибридными графическими системами (AMD Radeon + NVIDIA integrated), используя универсальный Overlay Hijacking.
