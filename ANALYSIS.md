# Технический анализ: Интеграция HyperBone VMM

В текущую реализацию DayZ чита внедрена поддержка гипервизора на базе проекта **HyperBone**, что обеспечивает ультимативный уровень скрытности.

## 1. Архитектура VMM (Ring -1)
- **Blue Pill Virtualization:** Лоадер (`refactored_loader.cpp`) инициализирует VMX-окружение и переводит текущую сессию Windows в режим гостевой ОС.
- **EPT Shadowing (`hv_core.h`):** Реализована логика TLB Splitting. Код чита в памяти подменяется на лету: когда античит читает память, он видит оригинальный системный код, но когда процессор выполняет этот код — выполняется логика чита.
- **MSR LSTAR Hijacking:** Перехват системных вызовов (syscalls) происходит на уровне процессора, что обходит любые Ring 0 хуки (PatchGuard совместимо).

## 2. Безопасность и Стелс
Интеграция HyperBone позволяет:
1. Читать и писать память игры без использования функций ядра Windows.
2. Скрывать присутствие Manual Map образа от любых сканеров.
3. Обходить Secure Boot и другие механизмы проверки целостности ОС.

## 3. Требования для разработчика
- Поддержка **Intel VT-x** и **EPT**.
- Наличие **Windows Driver Kit (WDK)** для сборки компонентов гипервизора.
- Соблюдение инструкций по BIOS из файла **`HYPERVISOR.md`**.

Эта интеграция делает чит практически невидимым для BattlEye, так как он работает на уровне, недоступном для античита.
