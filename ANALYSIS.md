# DayZ Stealth Cheat: Анализ Архитектуры (v11 "No Stubs")

Этот документ описывает финальную реализацию проекта, объединяющую профессиональную модульность архитектуры `gbhv` и передовые методы скрытности для процессоров AMD.

## 1. Архитектура Gbhv (v11 Professional)
Проект был полностью перестроен на основе стандартов промышленного уровня:
- **vmm.cpp**: Центральный диспетчер, управляющий жизненным циклом гипервизора на всех ядрах.
- **svm.cpp**: Специализированный бэкенд для AMD Ryzen. Реализует прямую трансляцию VA->PA и обработку команд без использования API Windows.
- **npt.cpp**: Менеджер вложенных таблиц страниц. Настраивает 1:1 Identity Mapping всей памяти (16 ГБ+) через Huge Pages (2 МБ), что критично для скорости чтения данных DayZ.

## 2. Комплексная Скрытность (No Stubs)
В этой версии полностью устранены все "заглушки". Реализованы:
- **Маскировка MSR**: Перехват доступа к регистру `EFER` (0xC0000080). Гипервизор динамически подменяет бит `SVME`, делая себя невидимым для проверок античита BattlEye.
- **Защита таймингов (TSC)**: В обработчике `CPUID` предусмотрена компенсация задержек, возникающих при выходе в гипервизор, что предотвращает обнаружение по аномалиям времени выполнения инструкций.
- **Randomized Pool Tags**: Все ядерные аллокации помечены случайными тегами ('Gst1', 'Ctx3' и др.) вместо стандартных, чтобы forensic-сканеры не нашли следов гипервизора в пуле памяти.

## 3. Стабильность Windows 10/11
Мы реализовали динамическую синхронизацию **Guest State**:
- При запуске гипервизор копирует селекторы сегментов (CS, SS, DS, ES, FS, GS) и их атрибуты из реальной GDT системы. Это гарантирует, что переход в виртуализованный режим пройдет без критических ошибок (BSOD).

## 4. Инъекция и Логика
- **Thread Hijacking**: Проверенный метод инъекции путем перехвата потока отрисовки игры. Не оставляет следов в виде новых потоков (`CreateRemoteThread`).
- **AES-128 CBC**: Полезная нагрузка зашифрована и расшифровывается в памяти через Windows CryptoAPI за миллисекунды до инъекции. Ключ дешифровки немедленно уничтожается.
- **DayZ ESP**: Отрефакторенная логика из оригинального дампа обеспечивает эффективную фильтрацию игроков и стабильную отрисовку через hijacked overlays (AMD/NVIDIA).

Версия v11 — это не просто чит, а полноценный исследовательский фреймворк Ring -1. Он объединяет стабильность `gbhv`, гибкость C++ и специализированную логику для DayZ, являясь лучшим решением для систем на базе AMD.
