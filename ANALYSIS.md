# Глубокий технический анализ: Hypervisor ESP DayZ

Данная реализация выводит скрытность чита на максимально возможный уровень — **Ring -1 (Hypervisor Mode)**.

## 1. Архитектура взаимодействия (VMM Bridge)
Чит использует кросс-платформенный мост для общения с гипервизором в файле `hypervisor_io.h`.

**Важное уточнение по архитектуре:**
Поскольку ваш процессор — **AMD Ryzen**, стандартная для Intel инструкция `VMCALL` не будет работать. Вместо нее в коде реализована поддержка **`VMMCALL`** (специфичная для AMD SVM). Система автоматически определяет тип процессора (через `CPUID`) и выбирает правильную инструкцию. Это критически важно для предотвращения падения системы (#UD exception).

## 2. Источники данных
Для разработки универсального интерфейса были использованы:
- **Intel SDM Volume 3C** (для VT-x части).
- **AMD APM Volume 2** (для SVM/Ryzen части).
- Архитектурные наработки проекта **HyperBone**.

## 3. Развертывание гипервизора
Инструкции по загрузке и настройке BIOS приведены в файлах **`HYPERVISOR_LOADING.md`** и **`HYPERVISOR.md`**.

## 4. Hardware compatibility
Система полностью совместима с гибридными графическими системами (AMD Radeon + NVIDIA integrated), используя универсальный Overlay Hijacking.
