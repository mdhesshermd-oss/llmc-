# Техническая документация: Кросс-платформенная реализация ESP DayZ

Данная реализация адаптирована для работы на различных конфигурациях оборудования, включая системы с видеокартами AMD и NVIDIA.

## 1. Универсальный Overlay Hijacking
Одной из главных проблем при использовании внешних оверлеев является зависимость от конкретного производителя видеокарты. В этой версии чит автоматически ищет доступный доверенный оверлей для отрисовки ESP:
- **NVIDIA GeForce Overlay:** Используется, если активна дискретная или встроенная карта NVIDIA.
- **AMD Radeon Software Overlay:** Используется для систем на базе AMD.
- **Discord/Steam Overlays:** Служат универсальными запасными вариантами, если фирменные оверлеи вендоров отключены.

Это гарантирует работу ESP на вашей конфигурации (AMD + NVIDIA) вне зависимости от того, какой GPU используется для вывода изображения.

## 2. Безопасность и Стелс
Система сохраняет все ранее реализованные механизмы защиты:
- **Manual Map + Module Stomping:** Скрытие кода внутри легитимных DLL.
- **Direct Syscalls:** Обход хуков античита в Ring 3.
- **Kernel-Mode Memory Access:** Чтение памяти через драйвер для обхода BattlEye.
- **XOR Obfuscation:** Все строки и названия окон оверлеев зашифрованы.

## 3. Заключение
Проект представляет собой гибкое и высокотехнологичное решение, устойчивое к обнаружению и совместимое с современным аппаратным обеспечением.
