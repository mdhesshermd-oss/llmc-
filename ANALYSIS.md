# Технический анализ и Архитектура Реверс-Инжиниринга DayZ (v11.0)

## 1. Обзор проекта
Данный проект представляет собой высокотехнологичное решение для взаимодействия с памятью игры DayZ на уровне гипервизора (Ring -1). В основе лежит архитектура AMD SVM (Secure Virtual Machine), оптимизированная для процессоров Ryzen (в частности, для Ryzen 5 7535HS).

## 2. Основные компоненты

### А. Гипервизор (Core)
*   **svm.cpp / svm.h**: Реализация бэкенда AMD SVM. Обрабатывает VM-Exit (CPUID, VMMCALL, NPF).
*   **vmm.cpp / vmm.h**: Оркестрация процессоров (DPC Broadcast), управление контекстами ядер и синхронизация.
*   **npt.cpp**: Менеджер вложенных таблиц страниц (Nested Page Tables). Реализует Identity Mapping для 16 ГБ ОЗУ с использованием Huge Pages (2MB).

### Б. Скрытность и Уклонение (Stealth)
*   **NPT Cloaking (Shadow Pages)**: Динамическая подмена физических страниц при чтении/выполнении. Анти-чит видит "чистый" код, в то время как CPU выполняет "инфицированный".
*   **TSC Timing Protection**: Компенсация задержек VM-Exit. Гипервизор вычитает время своей обработки из счетчика TSC гостя, делая свое присутствие невидимым для проверок времени.
*   **MSR Masking**: Скрытие бита SVME в EFER, предотвращающее обнаружение активной виртуализации.

### В. Логика Чита (Logic)
*   **refactored_logic.cpp**: Чистая реализация ESP (Extra Sensory Perception).
    *   `sub_545D0` -> `IterateEntities()`
    *   `sub_748C0` -> `WorldToScreen()`
*   **manual_map.h**: Реализация Manual Map инъекции без использования системных вызовов Windows, что обходит большинство хуков.

### Г. Безопасность Payload
*   **AES-128 Encryption**: Шифрование основного модуля. Расшифровка происходит в памяти лоадера непосредственно перед инъекцией.
*   **Thread Hijacking**: Вместо `CreateRemoteThread`, проект использует перехват контекста существующих потоков игры для выполнения своего кода.

## 3. Процесс развертывания
1.  **Сборка**: Компиляция через Visual Studio 2022 (v143) с использованием MASM для ассемблерных вставок.
2.  **Шифрование**: Скрипт `encrypt_and_pack.py` упаковывает драйвер и payload.
3.  **Запуск**: `refactored_loader.cpp` инициализирует гипервизор, скрывает его и внедряет код в процесс игры.

## 4. Результаты анализа дампа
Анализ `hvgZq2E3.exe.bin1.bin.c` позволил восстановить структуру игровых объектов. Смещение игрока (Player Offset) подтверждено как `0x158`. Математические функции проекции координат полностью восстановлены и оптимизированы под современные наборы инструкций (AVX).
