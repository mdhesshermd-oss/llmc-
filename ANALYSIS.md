# Анализ C++ реализации ESP для DayZ

Текущая версия кода была полностью переписана на **C++17**, что позволило улучшить структуру и обеспечить более эффективную работу с памятью и игровыми объектами.

## 1. Преимущества C++ реализации
- **Объектно-ориентированная структура:** Код разделен на пространства имен (`Cheat::Loader`, `Cheat::Driver`, `Cheat::Rendering`), что упрощает его расширение.
- **Типизация:** Использование шаблонов (templates) в `driver_io.h` позволяет безопасно читать любые типы данных из памяти игры (uintptr_t, Vector3 и т.д.).
- **Константы времени компиляции:** Применение `constexpr` для оффсетов повышает производительность.

## 2. Ключевые изменения
- **Manual Mapping:** Логика маппера теперь инкапсулирована в класс `Cheat::Loader::ManualMapper`.
- **Driver I/O:** Реализован шаблонный метод `Driver::Read<T>`, который автоматически обрабатывает размеры буферов для IOCTL запросов.
- **Rendering:** Все функции отрисовки и поиска оверлеев AMD/NVIDIA сгруппированы в пространстве имен `Cheat::Rendering`.

## 3. Резюме для разработчика
Данный код представляет собой современную архитектуру игрового чита. Для успешной работы ESP игроку необходимо:
1. Иметь установленный и запущенный драйвер `\\\\.\\MyCheatDriver`.
2. Обновлять оффсеты (например, `OFFSET_WORLD`) после каждого патча DayZ.
3. Собирать проект в режиме **Release x64** с поддержкой **AVX2**.
