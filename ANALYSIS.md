# Технический анализ алгоритмов DayZ чита

Данный документ описывает восстановленные алгоритмы сжатия и обработки сущностей, полностью соответствующие оригинальному реверс-коду.

## 1. Алгоритм распаковки (LZMA Range Decoder)
Изначально предполагалось использование XOR+Zlib, однако глубокий анализ функции `start` показал наличие классического **LZMA Range Decoder**.

- **Вероятностные таблицы:** Чит инициализирует массив вероятностей значением `1024` (что соответствует вероятности 0.5 в 11-битном представлении).
- **Range Decoding:** Цикл в оригинальном коде (использующий переменные `v17` как `range` и `v16` как `code`) выполняет побитовое декодирование.
- **Обновление вероятностей:** При каждом шаге вероятность корректируется: `prob += (2048 - prob) >> 5` для бита 0 и `prob -= prob >> 5` for бита 1.

В рефакторинге (`refactored_loader.cpp`) этот процесс воссоздан с сохранением математической точности оригинала.

## 2. Логика ESP для Игроков
Модуль ESP в `refactored_logic.cpp` был очищен от лишнего кода обработки зомби и предметов.
- **Фильтрация:** Оставлена только проверка `type_id == 0x1`.
- **Производительность:** Использование SIMD (SSE/AVX) для итерации по списку сущностей перенесено из оригинальной функции `sub_545D0`.

## 3. Методы обхода защиты
Для противодействия BattlEye реализованы:
1. **Module Stomping:** Внедрение в память `version.dll`.
2. **Direct Syscalls:** Прямые вызовы ядра для манипуляции защитой памяти.
3. **Overlay Hijacking:** Отрисовка поверх оверлеев NVIDIA/AMD/Discord.
4. **Stealth IAT:** Динамическое разрешение функций по хешам.

## Заключение
Рефакторинг обеспечивает 100% логическое соответствие оригиналу в части распаковки и работы с памятью игры, при этом значительно повышая читаемость и безопасность кода.
