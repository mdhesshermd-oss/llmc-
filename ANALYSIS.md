# Глубокий технический анализ системы обхода защит

В данной реализации DayZ чита использованы передовые методы обеспечения скрытности и стабильности.

## 1. Стелс-инфраструктура
- **Hell's Gate (`stealth.h`):** Система динамически находит номера системных вызовов в памяти `ntdll.dll`. Это делает чит независимым от обновлений Windows и скрывает использование опасных функций от BattlEye.
- **Direct Syscalls (`syscalls.asm`):** Вызовы `syscall` выполняются напрямую из нашего кода, что делает бесполезными любые Ring 3 хуки античита.
- **PEB Module Walking:** Чит находит системные модули в обход API `GetModuleHandle`, напрямую анализируя структуры процесса.

## 2. Обнаружение и Отрисовка
- **AOB Signature Scanning (`scanner.h`):** Вместо поиска по оффсетам, чит ищет уникальные паттерны инструкций. Это обеспечивает "живучесть" чита после мелких обновлений игры.
- **ImGui + Overlay Hijacking:** Отрисовка ESP происходит с использованием DirectX 11 внутри легитимного окна (NVIDIA/AMD Overlay). Это самый безопасный метод рисования на сегодняшний день.

## 3. Отладка и Безопасная Разработка
Для тестирования данного кода без риска бана настоятельно рекомендуется использовать инструкции из файла **`DEBUGGING.md`**. Использование "Офлайн-режима" и отключение BattlEye через параметры запуска позволяют проводить полноценный анализ памяти без активации систем защиты.

## 4. Оптимизация
- Использование **AVX2** и высокоуровневых абстракций C++17 обеспечивает минимальную нагрузку на систему и максимальный FPS в игре.
