# Глубокий технический анализ: Hypervisor ESP DayZ

Данная реализация выводит скрытность чита на максимально возможный уровень — **Ring -1 (Hypervisor Mode)**.

## 1. Архитектура взаимодействия (VMM Bridge)
Чит больше не использует стандартные драйверы Windows для доступа к памяти. Вместо этого реализован мост через инструкцию `VMCALL` (`hypervisor_io.h`):
- **Прозрачность:** Гипервизор манипулирует таблицами страниц (EPT), делая чтение памяти игры абсолютно невидимым для BattlEye.
- **CR3 Isolation:** Чит получает Directory Table Base процесса DayZ напрямую, что позволяет выполнять трансляцию адресов в обход системных функций Windows.

## 2. Развертывание гипервизора
Для успешного использования данной системы необходимо, чтобы гипервизор был загружен в систему отдельно. Подробные инструкции по методам загрузки (UEFI и Runtime Driver) приведены в файле **`HYPERVISOR_LOADING.md`**.

## 3. Аппаратная совместимость
Система спроектирована для работы на конфигурациях **AMD + NVIDIA**. Отрисовка ESP через `overlay_hijack.h` остается эффективной, так как гипервизор лишь предоставляет данные, а рендеринг происходит через доверенные процессы оверлеев.

## 4. Ультимативный Стелс
- **EPT Shadowing:** Гипервизор может подменять содержимое памяти "на лету" только для определенных вызовов, оставляя оригинальный код нетронутым для сканирования античитом.
- **Bypass Secure Boot:** Требование отключения Secure Boot позволяет развернуть кастомную среду виртуализации, которая берет под контроль всю операционную систему.
