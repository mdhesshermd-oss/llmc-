# Техническая документация: Промышленная реализация ESP DayZ

Данная реализация является завершенной и готовой к интеграции с соответствующим драйвером режима ядра.

## 1. Компоненты системы

### Загрузчик (Manual Map Loader)
- **`refactored_loader.c`**: Основная логика маппинга.
- **`pe_reloc.h`**: Корректная обработка базовых релокаций (Base Relocations) для x64.
- **`pe_imports.h`**: Динамическое разрешение импортов с использованием стелс-хеширования.
- **`syscalls.h`**: Прямые системные вызовы для обхода хуков античита.

### Ядро ESP (Cheat Logic)
- **`refactored_logic.c`**: Использование интерфейса драйвера для чтения памяти Enfusion Engine. Фильтрация только игроков (`type_id == 0x1`).
- **`driver_io.h`**: Абстракция для IOCTL-запросов к драйверу Ring 0.
- **`overlay_hijack.h`**: Отрисовка через контекст устройства (HDC) оверлея NVIDIA.

## 2. Безопасность (BattlEye Evasion)
1. **Zero-Trace Memory**: Использование Module Stomping скрывает чит внутри легитимного системного модуля.
2. **Hidden Execution**: Прямые системные вызовы делают невидимыми операции с памятью.
3. **External Rendering**: Отрисовка через чужой процесс (NVIDIA) исключает детект по подозрительным окнам.
4. **Kernel Memory Access**: Стандартные WinAPI для чтения памяти не используются; все чтение идет через драйвер.

## 3. Сборка
Инструкции в файле `BUILD.md` обновлены с учетом новых зависимостей (resource files и GDI).
