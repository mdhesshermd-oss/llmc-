# Детальный технический анализ кода чита DayZ

В ходе анализа декомпилированного файла `hvgZq2E3.exe.bin1.bin.c` были восстановлены алгоритмы работы основных компонентов чита.

## 1. Общая архитектура
Приложение использует стек **Tauri (Rust + WebView)**. Основная логика манипуляции памятью игры вынесена в нативные Rust-функции, которые экспортируются через интерфейс Tauri.

## 2. Разбор ключевых алгоритмов

### Система ESP и цикл обработки сущностей (`sub_545D0`)
Эта функция отвечает за перебор всех объектов в игровом мире для отрисовки меток.
- **Оптимизация:** Чит использует SIMD (инструкции `_mm_load_si128`, `_mm_movemask_epi8`), чтобы обрабатывать список указателей на объекты блоками по 16 штук. Это минимизирует задержки при большом количестве объектов (игроков, зомби).
- **Смещения (Offsets):**
    - Указатель на список сущностей находится по смещению `+48` от контекста чита.
    - Количество сущностей (count) находится по смещению `+72`.
    - Статус активности модуля проверяется по смещению `+164`.
- **Взаимодействие с игрой:** Для каждого объекта вызывается функция по адресу `0x7FFFB4492770`, которая возвращает свойства объекта (здоровье, тип, позиция).

### Логика WorldToScreen и проверка видимости (`sub_748C0`)
Функция проверяет, попадает ли 3D-точка (позиция игрока) в 2D-плоскость экрана.
- **Проекция:** Вызывает математическое ядро `0x66F917` для преобразования 3D-вектора в экранные координаты.
- **Масштабирование (DPI):** Чит динамически получает масштаб интерфейса (DPI) через вызов по адресу `0x850230` и делит полученное значение на 96.0 для корректной отрисовки на 4K-мониторах.
- **Viewport Clipping:** Координаты проверяются на вхождение в прямоугольник окна игры (ViewportInfo). Если объект находится сзади игрока или за пределами окна, отрисовка ESP для него отключается.

## 3. Заключение
Код демонстрирует профессиональный подход к разработке: использование Rust для безопасности памяти, SIMD для производительности и Tauri для удобного UI. Логика полностью завязана на динамическом анализе объектов игрового движка DayZ (Enfusion Engine).
