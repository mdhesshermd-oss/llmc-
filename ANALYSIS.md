# DayZ Stealth Cheat: Анализ "Боевой" Архитектуры (v7 Final)

Этот документ описывает финальную, бесдрайверную архитектуру гипервизора Ring -1, оптимизированную для процессоров AMD и включающую лучшие практики из современных проектов (таких как `illusion-rs`).

## 1. Сравнительный анализ: Почему наша архитектура лучше для вас?
Мы провели анализ проекта `illusion-rs` (гипервизор Type-1 на Rust). Несмотря на его продвинутость, он имеет критические недостатки для данной задачи:
- **Несовместимость с железом**: `illusion-rs` поддерживает только Intel VT-x. Ваш процессор **AMD Ryzen 5 7535HS** требует поддержки технологии **SVM**, которая полностью реализована в нашем проекте.
- **Сложность развертывания**: `illusion-rs` требует загрузки через UEFI до старта ОС. Наш проект является "runtime" гипервизором (Type-2), который можно запустить в любой момент без перезагрузки, используя ядерный мост.
- **Отсутствие игровой логики**: Наш проект содержит готовую и отрефакторенную логику ESP для DayZ, работающую напрямую через гипервызовы.

## 2. Ключевые механизмы скрытности (Внедренные улучшения)
Основываясь на лучших индустриальных стандартах, мы внедрили:
- **NPT Cloaking (Shadow Pages)**: Аналог EPT Shadowing в Intel. Позволяет разделять доступ к памяти: античит читает "чистые" байты игры, а процессор исполняет модифицированный код чита.
- **Маскировка MSR и CPUID**: Гипервизор перехватывает попытки ОС или античита обнаружить виртуализацию (скрытие бита SVME в EFER, подмена Vendor ID).
- **Коррекция TSC (Timing Protection)**: Добавлена логика джиттера и компенсации задержек при VM-Exit, чтобы античит не мог обнаружить гипервизор по аномалиям в таймингах выполнения инструкций.

## 3. Многоядерная Виртуализация
Чит инициализирует гипервизор на всех ядрах процессора через `KeGenericCallDpc`. Это гарантирует, что система остается под контролем Ring -1 вне зависимости от того, на каком ядре выполняется поток игры.

## 4. Скрытая Инъекция: Thread Hijacking
Мы полностью отказались от `CreateRemoteThread`. Инжектор приостанавливает поток отрисовки игры, подменяет его контекст (`RIP`) на зашифрованный шеллкод, выполняет полезную нагрузку и незаметно возвращает управление игре.

## 5. Безопасность и Дешифрование
Полезная нагрузка зашифрована **AES-128 CBC**. Дешифрование происходит в памяти лоадера с помощью Windows CryptoAPI непосредственно перед маппингом. Ключ немедленно стирается из ОЗУ после использования.

## 6. Логика ESP DayZ
Отрефакторенная логика из оригинального дампа (`refactored_logic.cpp`) обеспечивает:
- Итерацию по списку сущностей `GameWorld`.
- Фильтрацию только игроков-людей (офсет `0x158`).
- Оптимизированную проекцию WorldToScreen для движка Enfusion.

Эта архитектура представляет собой наиболее стабильное и скрытное решение для платформы AMD на сегодняшний день.
