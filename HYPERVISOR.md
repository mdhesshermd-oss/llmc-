# Руководство по настройке Hypervisor-чита (Universal)

Для работы чита через гипервизор (Ring -1) необходимо включить виртуализацию в BIOS. Процедура отличается в зависимости от вашего процессора.

## 1. Настройка BIOS для AMD (Ryzen 5 7535HS и др.)
- **Включить SVM Mode (Secure Virtual Machine):** Обязательно для работы архитектуры AMD-V.
- **Включить IOMMU:** Необходим для корректного маппинга памяти через NPT.
- **Отключить Secure Boot:** Для загрузки кастомных компонентов.

## 2. Настройка BIOS для Intel
- **Включить Intel Virtualization Technology (VT-x).**
- **Включить VT-d.**
- **Отключить Secure Boot.**

## 3. Настройка Windows (Общее)
- **Включить Hyper-V:** В "Компонентах Windows".
- **Отключить VBS (Virtualization-Based Security):** В настройках безопасности Windows (Изоляция ядра), чтобы избежать конфликтов с гипервизором чита.

## Как проверить готовность
Запустите `Task Manager` (Диспетчер задач) -> вкладка `Performance` (Производительность) -> `CPU`. В правом нижнем углу должно быть написано **Virtualization: Enabled**.
