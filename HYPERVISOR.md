# Руководство по настройке Hypervisor-чита

Виртуализация (Ring -1) — это самый продвинутый и безопасный уровень работы чита, позволяющий полностью скрыть его присутствие от BattlEye.

## Требования к системе
Для работы данной реализации ваш ПК должен поддерживать аппаратную виртуализацию и быть правильно настроен.

### 1. Настройка BIOS/UEFI
- **Включить VT-x (Intel Virtualization Technology):** Необходима для работы гипервизора.
- **Включить VT-d (Directed I/O):** Требуется для прямого доступа к памяти в обход ОС.
- **Отключить Secure Boot:** Позволяет загружать кастомные гипервизоры и драйверы без цифровой подписи Microsoft.

### 2. Настройка Windows
- **Включить Hyper-V:** В разделе "Включение или отключение компонентов Windows" убедитесь, что Hyper-V включен. Чит использует встроенные механизмы виртуализации Windows для создания скрытого слоя.
- **Memory Integrity (HVCI):** Рекомендуется отключить в настройках изоляции ядра, чтобы избежать конфликтов с EPT-хуками.

## Принцип работы (Stealth Layer)
Чит работает на уровне выше операционной системы (Ring -1). Когда читу нужно прочитать память игры:
1. Он выполняет инструкцию `VMCALL`.
2. Процессор перехватывает это управление и передает его гипервизору.
3. Гипервизор читает физическую память напрямую через таблицы EPT (Extended Page Tables).
4. BattlEye, работающий внутри Windows (Ring 0), физически не может увидеть этот процесс, так как гипервизор находится "под" ним.

---

## Преимущества перед драйвером
| Метод | Видимость для BattlEye | Риск бана |
| :--- | :--- | :--- |
| **Driver (Ring 0)** | Средняя (анализ стека, проверка подписи) | Есть |
| **Hypervisor (Ring -1)** | Нулевая (прозрачный доступ) | Минимальный |

## Внимание
Использование гипервизора требует глубоких знаний системного программирования. Данный код является интерфейсом взаимодействия; сам гипервизор (VMM) должен быть загружен в систему отдельно.
