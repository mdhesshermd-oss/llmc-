# Инструкция по сборке и эксплуатации (AMD SVM Edition)

## Требования
*   **ОС**: Windows 10/11 x64 (рекомендуется 22H2+).
*   **Процессор**: AMD Ryzen (с поддержкой SVM). Проверено на Ryzen 5 7535HS.
*   **Среда**: Visual Studio 2022, Windows Driver Kit (WDK).

## Шаги сборки
1.  Откройте проект в Visual Studio.
2.  Убедитесь, что для файла `svm_bridge.asm` и `syscalls.asm` установлен тип элемента "Microsoft Macro Assembler".
3.  Соберите решение в конфигурации **Release / x64**.
4.  Запустите `python encrypt_and_pack.py` для генерации зашифрованного контейнера.

## Использование
1.  Запустите лоадер от имени администратора.
2.  Лоадер выполнит следующие действия:
    *   Проверка поддержки SVM (`preflight.h`).
    *   Загрузка гипервизора в память.
    *   Вход в режим Guest через `GbhvSvmLaunch`.
    *   Скрытие признаков присутствия гипервизора.
    *   Инъекция ESP-модуля в DayZ.

## Безопасность (Stealth)
*   Драйвер не оставляет записей в `MmUnloadedDrivers`.
*   Все PE-заголовки затираются после инициализации.
*   Используются рандомизированные Pool Tags (`'Gst1'`, `'Lst2'`, `'Ctx3'`).
*   Связь с гипервизором защищена секретным ключом `0x5A4F524F5F444159`.

## Важное замечание
Данное ПО разработано исключительно в образовательных целях для демонстрации техник работы с гипервизорами AMD.
