# Инструкция по сборке и упаковке проекта

Этот проект требует предварительной упаковки основной библиотеки (`cheat_core.dll`) перед компиляцией лоадера.

## Этап 1: Сборка основной библиотеки
Сначала соберите ESP логику в DLL файл.
```bash
cl.exe /LD /O2 /arch:AVX2 refactored_logic.c /Fe:cheat_core.dll
```

## Этап 2: Шифрование и упаковка
Используйте Python-скрипт `encrypt_and_pack.py` для сжатия и XOR-шифрования полученной DLL. Скрипт создаст заголовочный файл `payload.h`, который будет вшит в лоадер.
```bash
python encrypt_and_pack.py cheat_core.dll payload.h
```

## Этап 3: Сборка лоадера
Теперь соберите лоадер, который использует `payload.h`. Лоадер будет содержать в себе зашифрованную DLL и распакует её прямо в памяти при запуске.
```bash
cl.exe /O2 refactored_loader.c /link /OUT:loader.exe
```

---

## Архитектурная схема
1.  **refactored_logic.c** -> `cheat_core.dll` (Основной функционал ESP).
2.  **encrypt_and_pack.py** + `cheat_core.dll` -> `payload.h` (Шифрованный массив байт).
3.  **refactored_loader.c** + `payload.h` -> `loader.exe` (Финальный файл лоадера).

## Примечание по безопасности
В данной версии используется простой XOR-ключ (0xAA). Для повышения скрытности рекомендуется заменить алгоритм в `encrypt_and_pack.py` и `refactored_loader.c` на более сложный (например, AES или кастомный алгоритм перестановки).
