# Проект DayZ Stealth (v11 Professional)

Этот репозиторий содержит финальную, полностью функциональную («No Stubs») реализацию бесшумного чита для DayZ на базе гипервизора AMD SVM.

## 🌟 Ключевые Особенности

- **Архитектура Gbhv**: Модульная и масштабируемая система на базе стандартов профессиональных гипервизоров.
- **Ring -1 Stealth**: Полная изоляция от ОС. Перехват MSR (EFER) и CPUID для сокрытия виртуализации.
- **NPT Shadow Pages**: Технология скрытия модифицированного кода от сканеров памяти.
- **Identity Mapping (2MB)**: Мгновенный доступ гипервизора к физической памяти через огромные страницы.
- **Thread Hijacking**: Внедрение в DayZ без использования палевных API Windows.
- **AES-128 CBC**: Шифрование полезной нагрузки промышленного уровня.

## 📂 Структура Проекта

- `vmm.cpp`: Управление многоядерной инициализацией.
- `svm.cpp`: Бэкенд AMD SVM (Exit Handler, VA Translator).
- `npt.cpp`: Менеджер вложенных страниц.
- `driver.cpp`: Ядерный мост для запуска системы.
- `refactored_loader.cpp`: Центральный контроллер (Дешифровка -> Запуск -> Инъекция).

## 🛠 Сборка и Использование

Подробная пошаговая инструкция по сборке в один файл находится здесь: **[BUILD_DETAILED.md](BUILD_DETAILED.md)**.

1. **Компиляция**: Visual Studio 2022 + WDK + MASM.
2. **Payload**: Шифрование через `encrypt_and_pack.py`.
3. **Загрузка**: Используйте KDMapper для `driver.sys`.
