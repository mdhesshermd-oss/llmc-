# Руководство по безопасной отладке чита в DayZ

Для разработки и тестирования чита без риска получить бан от BattlEye или VAC, необходимо использовать локальный сервер с отключенными системами защиты.

## 1. Запуск локального сервера (Offline/Local)

### Способ А: Офлайн режим (Самый безопасный)
DayZ поддерживает встроенный офлайн-режим, где античит не загружается вовсе.
1. В Steam откройте свойства DayZ -> **Launch Options**.
2. Введите: `-mission=dayzOffline.chernarusplus` (или другую карту).
3. Запустите игру. Вы окажетесь на карте в одиночку, BattlEye будет неактивен.

### Способ Б: Свой сервер (DayZ Server)
Если вам нужно тестировать сетевой код или взаимодействие с другими сущностями:
1. Установите **DayZ Server** из раздела "Tools" в Steam.
2. В папке сервера найдите файл `serverDZ.cfg`.
3. Убедитесь, что параметр `battleye = 0;` установлен (это отключает античит на сервере).
4. Запустите сервер через `DayZServer_x64.exe`.

---

## 2. Настройка клиента для отладки

Чтобы клиент не подключался к службам BattlEye при запуске:
1. Создайте ярлык для `DayZ_x64.exe` (находится в папке игры).
2. В поле "Объект" после кавычек добавьте следующие параметры:
   ```bash
   -nolauncher -nosplash -battleye=0
   ```
   - `-nolauncher` — запуск напрямую, минуя официальный лаунчер (который всегда грузит BE).
   - `-battleye=0` — принудительное отключение инициализации античита.

---

## 3. Важные правила безопасности
- **Никогда** не заходите на официальные или сторонние серверы с включенным BattlEye, если вы запускали свой лоадер или модифицировали память игры в текущей сессии Windows.
- **Перезагрузите ПК** перед выходом в онлайн. Некоторые изменения в памяти могут сохраняться (особенно если вы используете драйвер).
- Используйте **второй аккаунт Steam** для тестов, если это возможно. Даже с выключенным BE, Valve может зафиксировать подозрительные манипуляции с файлами через VAC.

## 4. Инструменты для отладки
При выключенном античите вы можете свободно использовать:
- **Cheat Engine** (не будет кикать за наличие процесса).
- **x64dbg** (позволяет ставить точки останова/breakpoints).
- **ReClass.NET** (для анализа структур в реальном времени).

Соблюдение этих инструкций позволит вам отлаживать ESP и другие функции чита в "стерильной" среде без риска потери основного аккаунта.
