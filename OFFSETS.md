# Руководство по поиску оффсетов для DayZ (Enfusion Engine)

При каждом обновлении DayZ адреса в памяти (оффсеты) меняются. Чтобы чит продолжал работать, вам нужно обновить константы в файле `refactored_logic.cpp`.

## Необходимые инструменты
1. **Cheat Engine** — для поиска базовых указателей.
2. **ReClass.NET** — для разбора структур объектов (игроков, мира).
3. **IDA Pro / x64dbg** — для глубокого анализа функций движка.

## Основные оффсеты и способы их поиска

### 1. World (Базовый адрес мира)
`World` — это корень всех объектов в игре.
- **Как искать:** В Cheat Engine ищите координаты своего персонажа (тип Float). Найдите адрес, который меняется при движении.
- Используйте функцию "Find out what accesses this address". Посмотрите на инструкции, которые читают координаты. Обычно они выглядят так: `movss xmm0, [rax+0x2C0]`. Здесь `rax` — это указатель на ваш объект игрока.
- Проследите, откуда берется адрес игрока. Обычно это цепочка: `DayZ.exe + GlobalOffset -> World -> LocalPlayer`.

### 2. EntityList (Список сущностей)
В Enfusion Engine список всех объектов находится внутри структуры `World`.
- **Как искать:** Откройте адрес `World` в ReClass.NET.
- Ищите массив указателей или структуру `Table` (размер обычно 8 байт на элемент).
- В DayZ оффсет `EntityList` часто находится в диапазоне `0x1E00 - 0x1F00`.
- Признак списка: большое количество указателей, ведущих к структурам, начинающимся с VTable движка.

### 3. TypeID (Идентификатор типа)
Чтобы отличить игрока от зомби, мы используем `type_id`.
- **Как искать:** В ReClass.NET сравните структуру вашего персонажа и структуру зомби.
- Найдите поле, которое у всех игроков равно `1`, а у зомби — другому значению (например, `2` или `4`).
- Обычно это поле находится в начале структуры сущности (около `0x150 - 0x170`).

### 4. Position (Координаты)
- **Как искать:** Ищите Float значения X, Y, Z. Они всегда идут подряд.
- Традиционный оффсет позиции в DayZ — `0x2C0`.

## Куда вставлять найденные значения

Откройте файл **`refactored_logic.cpp`** и обновите блок `constexpr` в классе `ESP`:

```cpp
namespace Cheat {
    namespace Features {
        class ESP {
        private:
            // ОБНОВЛЯТЬ ЗДЕСЬ:
            static constexpr uintptr_t OFFSET_WORLD = 0x413A238;     // Новый адрес World
            static constexpr uintptr_t OFFSET_ENTITY_LIST = 0x1E88;  // Новый оффсет списка
            static constexpr uintptr_t OFFSET_ENTITY_COUNT = 0x1E90; // Новый оффсет количества
            static constexpr uintptr_t OFFSET_PLAYER_POS = 0x2C0;    // Новый оффсет координат
            static constexpr uintptr_t OFFSET_TYPE_ID = 0x158;       // Новый оффсет ID типа
// ...
```

## Совет
Если вы нашли `VTable` игрока, вы можете использовать её адрес как уникальную сигнатуру для поиска через IDA Pro, что позволит автоматизировать нахождение оффсетов после патча.
